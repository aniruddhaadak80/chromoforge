# services/agents — the Python side of foundry

A small FastAPI service that runs the *heavier* deterministic work off the web thread: batch
simulations and crew briefings. It needs no API keys and degrades gracefully — the Next.js app
computes everything locally via `packages/core`, so this service is an accelerator and a parity
oracle, never a dependency.

## What's inside

| File | Role |
|---|---|
| `main.py` | FastAPI app: `/healthz`, `/brief`, `/simulate`, `/simulate/batch` |
| `sim.py` | exact Python port of the TypeScript simulation (same PRNG quirks, same rounding) |
| `crew.py` | deterministic agent crew — the Navigator / Xenobiologist / Ethicist |
| `parity/run_parity.py` | diffs the Python (and optionally Rust) engine against TS fixtures |
| `parity/fixtures.json` | generated by `bun packages/core/scripts/gen-vectors.ts` — do not edit |
| `data/fetch_catalog.py` | optional refresh of the exoplanet seed from the NASA Exoplanet Archive |
| `tests/` | pytest: API contract + cross-language parity |

## Run it

```bash
cd services/agents
pip install -r requirements.txt
uvicorn main:app --port 8787
```

## Parity

```bash
python -m parity.run_parity           # python vs typescript fixtures
python -m parity.run_parity --rust    # also builds + runs the rust engine (needs a linker)
# or everything at once, from the repo root:
sh bin/parity.sh
```

Parity requires bit-level care: mulberry32 with JS `Math.imul` semantics and JavaScript's
`Math.round` (floor(x+0.5)). The fixtures encode the TypeScript engine's exact output; if a
fixture and an implementation disagree, the fixture wins until you change the TS engine and
regenerate.
